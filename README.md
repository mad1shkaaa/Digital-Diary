# Digital-Diary — «Дневник моей жизни»

Hackathon final product. Веб-дневник, где каждый прожитый день становится картиной из ваших слов, фото, видео, музыки и голоса.
Интерфейс на трёх языках: қазақша, English, русский.

**Открыть:** `index.html`. Это один готовый файл: его можно открыть в Chrome или Edge либо выложить на GitHub Pages.
Нужен интернет: 3D-движок three.js и шрифты грузятся из CDN.

## Возможности
- Выбор языка, регистрация и вход «через Google / Apple» (прототип, аккаунты хранятся на устройстве). Сессия держится 3 дня.
- 3D-конструктор героя по пояс с вращением. Пропорции человеческие.
  - 24 причёски, глаза, брови, форма лица, тон кожи, 16 вещей одежды, аксессуары.
  - Полный RGB-спектр для волос, глаз, одежды и аксессуаров.
  - Отмена, повтор и сброс.
- Сливово-золотой фон с созвездиями и астролябией. Фон вращается вместе с героем, за героем светится золотой ореол.
- Переход «телепорт»: ускорение, затягивание по краям и вспышка, после чего открывается мозг «Архив Воспоминаний».
- Архив: годы идут рядами слева направо, внутри ряда листаются месяцы. Картина месяца — коллаж фото, подсвеченный цветом преобладающей эмоции.
- День:
  - Живое фото: мягкое покачивание без искажения кадра. Есть статичный режим и полноэкранное погружение.
  - Рамка фото парит и «дышит».
  - Видео и Live Photo проигрываются без звука. По кнопке включается просмотр со звуком: музыка и озвучка встают на паузу и продолжаются с того же места.
  - Стикер эмоции стоит справа от даты. Для каждого фото можно выбрать свою эмоцию или применить одну ко всем фото.
  - В меню ⋯ можно отредактировать день: дату, текст, настроение, музыку и голос. Там же удаление дня.
- Запись дня: текст можно надиктовать голосом, фото и видео, настроение, музыка, голос рассказчика.
- Альбомы: кнопка рядом с настройками. Альбом можно собрать из фото любых дней и выбрать обложку. Есть общие альбомы по почтам участников.

## Музыка
- **Встроенная библиотека.** 14 оригинальных треков без авторских прав, синтезируются прямо в браузере. У каждого свои гармония, мотив и инструмент: фортепиано, вальс, домбра, гитара, струнные, шкатулка, эмбиент, электроника.
- **Pixabay Music.** У Pixabay нет официального API для музыки: [официальное API](https://pixabay.com/api/docs/) отдаёт только изображения и видео. Поэтому на сайте сделан импорт:
  1. Кнопка открывает подборку Pixabay под настроение дня.
  2. Скачанный трек загружается кнопкой «⬆ Загрузить трек».
  3. Сайт сам определяет темп, лад и энергию трека. Трек попадает в библиотеку и участвует в автоподборе «по вайбу».
- **«Без музыки».** Музыка гарантированно не играет. Ошибка, из-за которой звук продолжал звучать, была в повторном запуске трека, она исправлена.

## Голоса рассказчиков
7 персонажей с описаниями из ТЗ: Мечтательная девушка, Простой парень, Уютная бабушка, Рассказчик, Солнечная девушка, Спокойный друг, Нежная поэтесса.
У каждого 4 эмоциональных режима: Радостно, Мягко и нежно, Ностальгично, Мечтательно. Режим меняет интонацию, паузы, акценты и разброс высоты, а не только скорость.
Голос выбирается при записи и при редактировании дня. В настройках есть «Студия голосов» с любым текстом и прослушиванием.

Как устроено:
1. **Без сервера** (работает сразу).
   - Используются голоса браузера (Web Speech API).
   - Голос подбирается по языку и полу персонажа, профиль задаёт темп, высоту и длину пауз.
   - Самые живые голоса — в Microsoft Edge (голоса «Natural», есть казахские).
   - Возраст и тембр (бабушка, глубокий бас) так имитируются лишь приблизительно.
2. **Нейросетевые голоса** через `server/tts-proxy.mjs` (Node 18+). Ключ API хранится только на сервере.
   - **Рекомендуется ElevenLabs Voice Design.**
     - Голос создаётся по текстовому описанию, без записи чужого голоса. Это ровно формат описаний из ТЗ.
     - Скрипт `server/create-voices.mjs` создаёт 7 голосов и сохраняет превью.
     - Эмоциональный режим передаётся через `voice_settings`.
     - Документация: [Voice Design](https://elevenlabs.io/docs/eleven-api/guides/how-to/voices/voice-design), [design API](https://elevenlabs.io/docs/api-reference/text-to-voice/design).
     - Условия коммерческого использования зависят от тарифа: проверьте их в условиях ElevenLabs.
   - **Альтернатива — OpenAI TTS.**
     - Встроенные голоса плюс параметр `instructions`, который управляет эмоциями и интонацией. Своих голосов по описанию в обычном TTS API нет.
     - По [документации](https://developers.openai.com/api/docs/guides/text-to-speech) модели `tts-1`, `tts-1-hd` и `gpt-4o-mini-tts` объявлены устаревшими и отключаются 6 января 2027. Для долгой поддержки нужен переход на Realtime API.
     - Голос из приложения ChatGPT нельзя автоматически использовать через API.

```bash
ELEVENLABS_API_KEY=... node server/create-voices.mjs
```

```bash
PROVIDER=elevenlabs ELEVENLABS_API_KEY=... VOICE_IDS='{"dreamy":"..."}' node server/tts-proxy.mjs
```

После запуска на сайте откройте «Настройки → Студия голосов → Сервер нейро-озвучки» и укажите `http://localhost:8787/tts`.

## Ограничения прототипа
- Аккаунты, записи и альбомы хранятся в браузере: localStorage и IndexedDB.
- Общие альбомы видны другим аккаунтам на том же устройстве. Для синхронизации между телефонами нужен сервер.
- Настоящий вход через Google и Apple требует сервера и ключей OAuth.
- Голосовой ввод работает в Chrome и Edge. Распознавание казахского зависит от браузера.

## Разработка
Исходники лежат в `src/`. Итоговый `index.html` собирается командой:

```bash
./src/build.sh
```

Модули в `src/`:

| Файл | Что внутри |
|---|---|
| `engine.js` | Анализ настроения, художественные стили, синтез музыки |
| `i18n.js` | Языки, настроения, треки |
| `theme.js` | Фон и RGB-палитра |
| `avatar.js` | 3D-герой |
| `voices.js` | Голоса и диктовка |
| `albums.js` | Альбомы и переход-телепорт |
| `app.js` | Экраны |
